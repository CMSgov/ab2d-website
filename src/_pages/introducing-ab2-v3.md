# {{ page.page_title }}

This documentation is for v1 and v2 users migrating to AB2D v3. If you’re new to AB2D, our <a href="https://ab2d.cms.gov/production-access">standard AB2D documentation</a> may be the best place to get started.
AB2D v3 became available November 3, 2026. Access to v1 and v2 will be removed on July 30, 2027. This documentation summarizes v3 changes and improvements while providing detailed steps to migrate.
